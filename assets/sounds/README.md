# SFX 差し替えガイド

現在は本番音源が無いため、index.html 内の `SFX` モジュールが Web Audio API で
効果音を仮生成しています(ビープ/シンセ音)。

以下のファイル名でここに音声ファイルを置くと、コード変更なしで自動的に
そちらが優先再生されます(ファイルが無い/読み込めない場合は仮音にフォールバック)。

| ファイル名 | 発生タイミング |
|---|---|
| flap.mp3 | 羽ばたき(タップ)した時 |
| befriend.mp3 | 敵を上から踏んで仲間にした時 |
| recollect.mp3 | 散らばった仲間を拾い直した時 |
| hit.wav | 横からぶつかって尻尾散乱した時(ミニを連れている場合) |
| 風船割れる.mp3 | 横からぶつかってバルーンを失った時(ミニを連れていない場合) |
| deliver.wav | 巣に納品した時 |
| one_miss.wav | バルーンが2つとも割れてミスになった時(巣に強制送還) |
| きらきら輝く3.mp3 | 金色のレアミニを巣に届けた時、帰巣効果音(deliver.wav)の最後に鳴る |
| 可愛く輝く1.mp3 | 金色のレアミニが画面に出現した時 |

形式は mp3 / wav などブラウザが再生できるものであれば可。

## BGM

`bgm/` 内の6曲(ふわふわの空 / ふわふわの空_2 / ふわふわの空_3 / Pixel Parade / Pixel Parade_2 / Pixel Parade_3)を
シャッフルしたプレイリストとして再生します(index.html の `BGM` モジュール)。1曲終わると自動で次の曲へ進み、
全曲聴き終わったら再シャッフルしてループします。

初回タップ/操作をきっかけに再生を開始し(ブラウザの自動再生制限のため)、右上の🔊/🔇ボタンでミュート切り替えができます(設定はlocalStorageに保存)。

曲を増やしたり差し替える場合は `BGM` モジュール内の `TRACKS` 配列にファイルパスを追加/変更してください。
